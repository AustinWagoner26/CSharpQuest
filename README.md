# C# Quest

C# Quest is a text-based role-playing game built using C# and .NET.

The project was created to practice object-oriented programming,
game logic, player interactions, and software development.
This is still an ongoing project that I am going to improve on.

## Features

- Three playable classes: Warrior, Mage, and Rogue
- Different starting health and attack statistics
- Three exploration paths: Forest, Mountain, and River
- Turn-based monster encounters
- Attack, defend, and escape actions
- Random gold rewards after victories
- Story progression to a village

## Technologies

- C#
- .NET 8
- Visual Studio Code
- Git and GitHub

## How to Run

1. Install the .NET 8 SDK.
2. Clone this repository.
3. Open the project folder in a terminal.
4. Run:

   dotnet run

## Project Structure

- Program.cs - Main game logic and story progression
- Player.cs - Player character properties
- Monster.cs - Enemy properties
- BattleSystem.cs - Battle system under development
